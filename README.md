# 带键盘事件的计算器

## 项目功能

- 支持加、减、乘、除四则运算
- 支持小数点输入
- 支持鼠标点击按钮
- 支持键盘输入数字和运算符
- 支持 Enter 计算、Backspace 退格、Escape 清空
- 能处理重复小数点和除数为 0 的异常情况

## 开发环境

- Qt Creator
- Qt 5.15.2 MinGW 64-bit
- C++

## 使用方法

1. 运行程序。
2. 使用鼠标点击按钮，或直接使用键盘输入表达式。
3. 按 Enter 或“=”得到结果。
4. 按 Backspace 删除最后一个字符。
5. 按 Escape 或“清空”恢复初始状态。
